# Capturas dos projetos demonstrativos

Capturas feitas em 24/11/2026, entre 14h47 e 14h49 no horário de São Paulo. A automação usou Chromium, viewport desktop de 1440 × 900, viewport mobile de 390 × 844 e DPR 1. As três páginas iniciais foram inspecionadas após o carregamento das fontes, das imagens visíveis e da transição de abertura. A galeria usa a captura desktop integral de cada uma.
